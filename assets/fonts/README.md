Static TTF instances of the brand fonts, used only to render Open Graph images
(`next/og` cannot read the woff2 files that `next/font` serves).

- Manrope 500 and 700: https://fonts.google.com/specimen/Manrope
- Cormorant Garamond 500 italic: https://fonts.google.com/specimen/Cormorant+Garamond

Both families are licensed under the SIL Open Font License 1.1.
